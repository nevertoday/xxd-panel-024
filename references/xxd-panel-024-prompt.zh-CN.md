# XXD Panel 024｜真实物象穿越几何情绪窗口生成核心

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的一张源照片。锁定一个主体或不可拆分关系、主要动作，以及至少三个源图专属线索。不得借用样张、旧成品或其他输入的主体、窗口方向、颜色、文案或构图。

## 一个窄长的浅色情绪窗口

根据主体重心、动作方向、轮廓走势与版面节奏，选择一个横向、纵向或斜向的窄长低饱和几何色块。它必须同时是视觉锚点与空间容器，不能变成装饰条、巨大背景板、多个色块或固定方向模板。

主体保持真实摄影感或精致写实质感，进入窗口内部并发生一次清楚的局部越界、破框、伸出或穿过。主体与色块必须像自然生长和空间穿透，而不是完整抠图贴在矩形上。保留单一焦点、真实材质、真实色彩与至少三个源图识别线索。

## 东方留白与轻微辅助层

背景使用白、浅灰或极浅暖色，以大面积留白建立轻盈秩序。只可加入极轻微的文化纹样、地形线、水波线、光影轮廓、线性图形或抽象符号，并且只能作为若隐若现的单一辅助层，不能形成第二主体、复杂装饰或可识别品牌图案。

主体可居中、偏心、纵向生长或横向舒展，但必须围绕色块与越界关系形成清楚、平衡的单一焦点。拒绝平均铺满、拥挤、过度对称、多个窗口、复杂拼贴与模板居中。

## 源图派生的商业色彩系统

从源图提取最有辨识度、最有精气神的颜色关系：窗口转为雾蓝、浅青、米白、淡粉、暖灰、浅金或其他协调的浅低饱和色；主体保留真实原生色彩；文字与辅助层只使用极少中性色。整体轻盈、干净、现代、精致，拒绝荧光、高饱和大色块、脏灰、全局滤镜和与源图无关的固定配色。

## 024 文字系统

自动文案从源图可见或有依据的主题、情绪、动作、状态或象征意义中提炼一个简短标题，并按需加入少量副标题、地点、状态词或微型注释。地点、日期、出处与事实编号必须由用户提供或可靠确认，不得为了高级感伪造。

标题可横排、竖排，或沿色块与主体关系排布；辅助信息以小字号、细字重和舒展节奏规整进入窗口边缘、越界方向或留白。使用目标语言自然的高端品牌／杂志排版等价物，不把拉丁宽字距、旋转或竖排机械套用到中文、日文、韩文或阿拉伯文。准确用户文案逐字保留；无文字模式不出现任何文字或伪文字。

## 模式与硬性验收


硬性验收：一个横向、纵向或斜向的窄长浅色低饱和几何窗口；方向由源图重心、动作与轮廓决定；真实摄影感或精致写实主体进入其中并发生一次明确局部越界；至少三个源图线索与主要动作仍可辨；白／浅灰／极浅暖背景与大面积留白；至多一层若隐若现的文化纹样或线性辅助；窗口浅色＋真实主体色＋极少中性色文字；一个简短标题与少量小字进入色块、主体和留白关系；无纯黑场、线稿主体、多窗口、完整贴图、复杂拼贴、荧光高饱和、厚重暗底、卡通、3D、模板居中或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
